# docs/

Screenshots, Wireshark captures (as images), diagrams and report drafts.

Suggested naming so files are easy to find when writing the report:

- `L1-*.png` basic chat (multiple clients, join/leave, disconnect handling)
- `L2-*.png` TLS setup and handshake
- `L3-*.png` additional security control (allowed vs blocked)
- `L4-*.png` firewall rules, ipconfig, cross-machine chat
- `L5-*.png` Wireshark plaintext vs encrypted
